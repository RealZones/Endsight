# The list Endsight ships is read first and this file on top of it, so an item added
# to a newer build reaches you without re-copying, and anything you re-tier here stays.
#
# One item per line: tier, a tab or spaces, then the item's name as it appears in chat.
# A note in brackets at the end - "Warden (pet)" - is shown in the settings but not
# matched, so a pet can be told from the boss it drops from.
# The name matches anywhere in the drop's name, longest match first, so "Dragon Fragment"
# covers every dragon's fragment and "Ender Dragon" the pet at any level. Case does not
# matter. Tiers: common, rare, epic, legendary. Anything not listed falls back to the
# server's own tier word, or the item's colour on a /debug line.
#
# These are set by rarity AND value, not the game's rarity colour - Aspect of the
# Dragons is gold in game and a 1/14 drop, so it is common here.
